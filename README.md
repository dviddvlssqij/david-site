# david-site

Сайт-визитка. Первая работа в портфолио.

## Что это
Чистый HTML + CSS + JS. Без фреймворков, без сборки, без зависимостей.
Открывается двойным кликом по `index.html`.

## Файлы
| Файл | Что внутри |
|---|---|
| `index.html` | Русская версия: тексты и структура |
| `en/index.html` | Английская версия |
| `styles.css` | Внешний вид обеих версий. Все цвета — в блоке `:root` сверху |
| `script.js` | Одна функция: появление блоков при прокрутке |

Стили и скрипт **общие** для двух языков. Правишь `styles.css` — меняются обе версии.

## Локальный просмотр
```
python3 -m http.server 8000
```
Открыть http://localhost:8000

## Что заменить перед публикацией
Заглушки `ЗАМЕНИТЬ` в **двух** файлах — `index.html` и `en/index.html`, секция `#contact`.

Одной командой из корня проекта:
```
grep -rl ЗАМЕНИТЬ . --include=*.html
```

## Деплой
GitHub → Cloudflare Pages. Папка публикации — корень, команда сборки не нужна.
